# Official Google Maps attribution logo

`google-maps-attribution.svg` is Google's own, unmodified Google Maps logo, taken from the official
`Google_Maps_Attribution_Assets.zip` that Google links from the Places API attribution requirements
(https://developers.google.com/maps/documentation/places/web-service/policies, retrieved 25 October
2026, file `GoogleMaps_Logo_DarkGray/GoogleMaps_Logo_DarkGray.svg`, SHA-256
`62c52df68d8f450c860d5d65068fc96d63c2dfaec849b91ac64b3256a898936e`).

It is required branding, not Google content: the Resource Collector displays Places data without an
embedded map, so Google requires its logo next to that data. The file is served read-only from the
application, is never modified, never imported into a business vault, never included in a website
resource kit and never used to imply Google endorses anything else on the page. Google's rules applied
here: non-outlined logo on a plain background, height 18px (16-19dp), clear space 10dp at the sides and
top and 5dp below, accessible label "Google Maps".

If Google publishes a newer asset pack, replace this file from that download and update the checksum;
do not redraw, recolour or crop the logo.
