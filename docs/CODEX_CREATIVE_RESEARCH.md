# Creative research — Adwoa’s House

25 October 2026 · working branch `feature/codex-creative-excellence` · owner approval pending.

## Evidence and limitations

Fifteen direct reference sites were loaded in real installed Playwright Chromium at 1440×900 and 390×844. Each received a viewport capture, a real 650px wheel scroll, an intermediate animation sample and a second capture. The native browser connector had no available browser. This was browser observation, not a source-code study or a claim of exhaustive interaction testing. Third-party screenshots stay outside the repository in `/tmp/dof-creative-research/`; structured observations are summarized below. No reference imagery or proprietary code was incorporated.

Discovery: [Awwwards](https://www.awwwards.com/) timed out in the web reader; [Siteinspire](https://www.siteinspire.com/) supplied a current design index; [Godly](https://godly.website/) redirected to recent.design, unavailable to the reader; [Hoverstat.es](https://www.hoverstat.es/) supplied interaction leads, including Ballet National de Marseille. These curation descriptions were not treated as proof of motion execution.

All fifteen direct sites returned HTTP 200 in Chromium. Some consent overlays, video delays and loading screens limited first-frame visual inspection. Runtime animation samples are observations at specific instants: zero sampled animations does not prove a static site, and JS/canvas animation need not appear in `document.getAnimations()`. No reference received a full accessibility audit, performance benchmark or measured easing-curve analysis. Route-to-route transitions were not exercised; none are asserted below. Fonts are computed family declarations, not licences to reuse those fonts.

## Decisions that reached implementation

1. **Photography before more decoration.** Ten original built-in image_gen assets follow one identity: two-storey bone plaster, square veranda columns, dark hardwood shutters and rails, clay paving, coastal stone and frangipani. A separate portrait arrival is composed for phones. No real property or recognizable person is a generation target. The retained licensed castle image supplies honest geographic context.
2. **A continuous journey.** Exterior → threshold → courtyard → table → room → materials → coast → evening invitation. Short public copy; room categories and commercial unknowns stay qualified locally. Detailed evidence stays in the concept-information dialog.
3. **Composition grammar.** Optional, validated `immersive-arrival`, `split-arrival`, `editorial-image`, `scroll-story`, `image-story`, `editorial-gallery` and `image-invitation` choices flow through editorial, builder, blueprint and the same Studio renderer. A `paper-and-ink` surface is direction-derived for cinematic builds. No business slug selects a React experience.
4. **Typography as several roles.** Keep the approved Instrument Serif/Public Sans pairing, but distinguish a panoramic title, a compact editorial cover, narrower scene titles, tabular scene numbers and legible text. A large serif is one role, not the composition. Both fonts remain self-hosted; only the existing Latin subset is claimed. The catalogue’s Ghanaian-language coverage gates remain unchanged.
5. **A visible native timeline.** A stable sticky image field wipes to the next scene as the corresponding in-flow chapter enters. The mask maps directly to document geometry. No wheel interception, fake scroll, arbitrary code or animation-library installation. Phone, no-JS, save-data and reduced-motion paths retain in-flow images.
6. **Real controls.** Room previews have buttons; the editorial gallery has a native dialog, previous/next controls, arrow keys and Escape. The prototype enquiry opens the existing notice; it never submits or collects data.

## Motion technology comparison

| Option | Fit and decision |
| --- | --- |
| [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) | Provides scrub, pinning and timeline coordination. A credible option for more complex sequencing; unnecessary dependency and lifecycle surface for three directly mapped masks. No GSAP runtime-cost claim was made without bundling it. |
| [CSS ScrollTimeline](https://developer.mozilla.org/en-US/docs/Web/API/ScrollTimeline) | Promising native timeline primitive. The Studio includes saved previews and multiple rendering contexts; retain a single explicit geometry implementation rather than split behavior across support paths for this pass. No unsupported universal-browser claim. |
| Web Animations API | Suitable for bounded imperative transitions. This narrative needs direct reversible scroll geometry, while existing CSS already owns entrances and hover/route transitions. No second timeline engine is needed. |
| [IntersectionObserver](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API) + CSS + rAF | Selected. Existing observer handles entrances; one passive scroll/resize listener batches reads before writes. Per-frame mask values are bounded and never enter React state. Preference changes and page navigation clean up the observer, listeners and custom properties. |

## Typeface licence evidence

[Instrument Serif’s source](https://github.com/Instrument/instrument-serif) and [Public Sans’s source](https://github.com/uswds/public-sans) were checked alongside bundled `OFL.txt` files. Both are supplied under SIL OFL 1.1. No proprietary reference font was downloaded or substituted. Existing WOFF2 files, preload bindings and `font-display: swap` are preserved. Licence text ships with the assets. The existing catalogue and binding checks continue to guard unbundled families and language coverage.

Originality boundary: no reference source code, photography, logo, custom font or distinctive complete layout was copied. This is an original fictional house, an authored narrative and bounded extensions to the existing renderer. Creative acceptance remains the owner’s decision.
