# Adwoa’s House — synthetic image production record

Created 25 October 2026 using the built-in `image_gen` tool and the `imagegen` skill. The owner explicitly authorized original fictional imagery, storage and local integration in this session. No paid external API, stock-download service or CLI API fallback was used.

The final responsive files are in `public/showcase/adwoas-house/concept-v2/`. Ten original PNG masters are also preserved locally in `output/imagegen/adwoa-source/` (ignored by Git to avoid storing large redundant masters); the originals remain in the generating session’s Codex generated-images directory too. Original filenames, workspace source paths, source SHA-256 hashes, actual dimensions, rendition paths, byte sizes and rendition hashes are recorded in `adwoa-concept-v2.json`. Project-referenced runtime files are all inside the repository and tracked. No asset depends on a temporary directory or on the source PNG location at runtime.

Permissions: inspection, storage and prototype use granted by the owner; export/publication denied pending separate approval. The blueprint explicitly classifies these as `synthetic_concept`, carries the credit and permission record, and still reports `publishReady: false`. These images are not evidence about a real business, a real hotel, a room inventory, Ghanaian construction practice or an actual location. The site's persistent concept disclosure, hero notes, gallery notes and footer explain that boundary.

## Production prompt set

The following records the final art-direction specification and the distinguishing instruction for each generation. The generation requests in the session contain the full expanded prompts. Every request specified photographic realism, no people, no text/logos/watermarks, no real-property reproduction and no copyrighted artwork.

**Master property prompt.** Photorealistic natural editorial architectural photograph; a believable compact two-storey courtyard guesthouse in a coastal residential quarter of Cape Coast, Ghana. Bone/chalk lime plaster, square plaster veranda columns, dark oiled Ghanaian hardwood louver shutters and doors, simple dark timber veranda railings, warm clay paving, rough grey coastal-stone low planting walls, frangipani and palms. Modest nine-room character, not a mansion or resort. Look through an open entrance gate toward the veranda at human eye level, with foreground depth. A woven low chair and soft late-afternoon shadows. Straight verticals, tactile imperfect surfaces, natural highlights, restrained greens and warm bone. No arches, swimming pool, thatch, exaggerated resort, European suite furniture, generic marble/chandeliers or recognizable existing hotel. Intended landscape request was 2400×1600; the actual returned master is **1536×1024**, not 2400×1600. No upscaling was performed.

## Visual continuity critique

All ten actual outputs were visually inspected. The square-column veranda, louver pattern, bone plaster, rail material, courtyard vegetation and warm material palette carry across the set. Bedroom joinery and textiles remain within the same vocabulary. The portrait arrival preserves the master facade; evening returns to that facade intentionally. No pool, restaurant, spa, sea-view room, person or branded artwork was added.

This is a **coherent concept set, not a geometrically validated 3D model**. Door spacing and furniture details vary between interior studies; no survey-level room adjacency or measured building continuity is claimed. The upper and garden bedrooms are alternative room studies, not verified room categories. Several frames remain quite warm in tone; a future commissioned photographic set should introduce more neutral morning light and people, only with consent and business-supplied facts. The real licensed castle photograph is separately credited and never described as a view from the guesthouse.

Renditions: 640, 1024 and, for landscape originals, 1536px wide WebP; no upscaling. The landscape and portrait arrival also have AVIF derivatives at the same widths, visually reviewed at phone scale. Native `picture` selects the portrait hero below 768px and offers AVIF with WebP fallback. The 1024px portrait AVIF is 164,523 bytes versus 373,150 bytes for WebP (56% less). The media registry separates formats and deduplicates widths within each source set. Width and height are explicit; the hero is eager/high priority and other plates use native lazy loading with low fetch priority. Original stock interior files remain preserved in Git history and on disk but are no longer selected by Adwoa’s editorial plan.
